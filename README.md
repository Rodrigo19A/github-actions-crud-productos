
# API CRUD de Productos

Proyecto desarrollado con Node.js y Express para
el Laboratorio 5.1 de GitHub Actions.

## Funcionalidades

- Registrar productos
- Listar productos
- Buscar productos por ID
- Actualizar productos
- Eliminar productos

## Tecnologías utilizadas

- Node.js
- Express
- Jest
- Supertest
- ESLint
- GitHub Actions

## Instalación

```bash
npm ci
```

## Iniciar servidor

```bash
npm start
```

## Ejecutar pruebas

```bash
npm test
```

## Analizar calidad del código

```bash
npm run lint
```

## Generar cobertura

```bash
npm run coverage
```

## Integración continua

GitHub Actions ejecuta automáticamente
el análisis de código, las pruebas unitarias
y la generación del reporte de cobertura.
